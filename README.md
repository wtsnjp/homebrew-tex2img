# homebrew-tex2img

> [!IMPORTANT]
> This tap is deprecated. TeX2img now has an [official Homebrew tap](https://github.com/doraTeX/homebrew-tex2img).
> During the transition period, this tap only mirrors the official formula.

Unofficial Homebrew Formula for [TeX2img](https://tex2img.tech/).

## Installing TeX2img

Please use the official tap:

```
$ brew install doratex/tex2img/tex2img
```

## Migrating from this tap

If you installed TeX2img from this tap, switch to the official tap with:

```
$ brew update
$ brew uninstall wtsnjp/tex2img/tex2img
$ brew untap wtsnjp/tex2img
$ brew install doratex/tex2img/tex2img
```

See also: <https://tex2img.tech/#migrate-homebrew>
